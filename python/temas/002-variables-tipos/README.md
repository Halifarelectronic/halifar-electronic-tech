# Variables y tipos

Por Ernesto Leal · Halifar Electronic Tech.

## Prerrequisitos y objetivo
Haber ejecutado la primera lección y reconocer print. Al terminar distinguirás texto, enteros, decimales y booleanos. Un nombre permite referirse a un valor; el tipo pertenece al valor. Python distingue mayúsculas y minúsculas. Usa nombres sin espacios: cantidad_componentes es válido.

## Materiales, instalación y ejecución
Computadora con Python 3; ejemplos comprobados con Python 3.11.2, sin dependencias. No hay sensor ni conexiones. Desde esta carpeta ejecuta `python3 nivel-1/main.py`, y después los niveles 2 y 3.

## Tres niveles explicados
1. Esencial: asigna Resistencia y 10 a dos nombres; print recupera sus valores. Resultado: Resistencia y 10 en líneas separadas.
2. Ampliado: añade un decimal y un booleano. type identifica el tipo, y __name__ obtiene su nombre legible. Resultado: str int y float bool. True lleva mayúscula; "True" sería texto.
3. Reto: reasigna cantidad mediante una suma. El lado derecho se evalúa antes de guardar el nuevo valor. Resultado: Antes: 10 y Después: 15. Cambia el incremento por 0 y -3: debes obtener 10 y 7 respectivamente. No se necesita entrada de datos ni condicionales.

## Diagnóstico
NameError suele indicar un nombre diferente; SyntaxError puede venir de comillas abiertas. Un decimal usa punto. No sumes texto y número sin una conversión explícita; las conversiones se estudiarán después.
