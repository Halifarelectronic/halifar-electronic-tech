# Crea tu app con React Native

**Por Ernesto Leal · Halifar Electronic Tech**

Curso para quien nunca ha programado. Primero aprenderás lógica y JavaScript; después construirás una misma aplicación por etapas. Cada avance conserva el trabajo anterior y explica qué se añadió, cómo ejecutarlo y qué debes observar.

Proyecto conductor: **Mi laboratorio**, una app para consultar fichas de componentes, buscar recursos y guardar favoritos. Al principio usa datos locales de ejemplo; la conexión a sensores reales será una ampliación posterior, no una función anunciada desde el inicio.
