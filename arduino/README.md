# Aprende Arduino

**Por Ernesto Leal · Halifar Electronic Tech**

Aprende programación y conexiones con prácticas pequeñas. Cada lección contiene materiales, placa y versión, esquema cuando corresponda, tres programas explicados y resultados esperados. El LED integrado permite empezar sin montar un circuito externo.
