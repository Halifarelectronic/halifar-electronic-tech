# BME280 con Arduino

**Por Ernesto Leal · Halifar Electronic Tech**

El BME280 mide temperatura, humedad y presión. Esta práctica lee las tres variables y las muestra por el monitor serie.

La guía inicial conserva materiales, comprobaciones de alimentación, explicación del programa, salida simulada y diagnóstico.

- [Abrir la guía completa](../../../ejemplos/sensores/HAL-002-bme280/README.md).
- [Abrir el programa Arduino](../../../ejemplos/sensores/HAL-002-bme280/src/bme280_prueba/bme280_prueba.ino).
- [Ficha de Bosch Sensortec](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bme280-ds002.pdf).

## Conexiones y validación

Falta identificar el módulo exacto para publicar un diagrama de cableado con pines y tensiones. No conectes un módulo solo por el aspecto de una ilustración. Compilación y prueba física pendientes de validar.
